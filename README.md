# Responsabilidad social en Ingeniería de Sistemas

## Descripción

Este proyecto académico demuestra cómo GitHub puede utilizarse para fomentar principios éticos como la transparencia, la responsabilidad, el respeto por la autoría y la protección de la información.

## Problemática

En los trabajos académicos grupales puede ser difícil conocer quién realizó cada aporte, qué información fue modificada y si todos los integrantes cumplieron responsablemente sus actividades.

## Objetivo

Utilizar las herramientas básicas de GitHub para registrar los aportes, organizar las actividades y promover un trabajo académico transparente y responsable.

## Principios éticos aplicados

- Transparencia: los cambios realizados quedan registrados.
- Responsabilidad: cada integrante responde por sus aportes.
- Respeto por la autoría: se reconoce a la persona que realizó cada contribución.
- Privacidad: no se publican datos personales ni información confidencial.
- Colaboración: los integrantes participan en el cumplimiento de un objetivo común.

## Uso de GitHub

GitHub permitirá almacenar los documentos del proyecto, registrar sus modificaciones y organizar las tareas académicas. No se utilizará programación, porque el propósito es demostrar cómo la plataforma contribuye a una actuación ética y responsable.
## Avance del proyecto

Se creó un documento de normas éticas y una tarea para verificar las referencias académicas. La actividad de verificación todavía se encuentra pendiente.
